# v0.5.1 Release Notes

Release date: August 26, 2026

## Highlights

- **Consumers of the published artifacts can compile against the public API
  again.** On JVM, JS and Wasm, `kcsg` and `kcsg-dsl` exposed dependency types
  in their public signatures while declaring those dependencies
  `implementation`, so Gradle published them only into the runtime variant. A
  project resolving `com.monkopedia:kcsg` from Maven Central could not name the
  types the API handed it. This was broken in v0.5.0 and in every prior
  release.
- Fixes a `difference()` result that was wrong — not imprecise, wrong — whenever
  the two operands did not overlap.
- `Edge.hashCode` is now consistent with `Edge.equals`.

## Bug Fixes

- **`difference()` returned an inverted subtrahend for non-overlapping
  operands.** Under `CSG_BOUND` and `POLYGON_BOUND` optimization, subtracting a
  solid that did not intersect the receiver returned volume `0.0` instead of the
  receiver unchanged — two disjoint unit cubes gave `0.0` where `8.0` is
  correct. `NONE` was unaffected. The cause was `differenceNoOpt` adopting the
  subtrahend and inverting it when its receiver was empty, which both bounds
  paths could reach. Shipped in v0.5.0 and every earlier release. (#58, PR #63)

- **`Edge.hashCode` disagreed with `Edge.equals`.** `equals` is
  direction-independent — an edge and its reverse are the same edge — but
  `hashCode` was not, so an edge and its reverse hashed differently and a hash
  container could hold both. (#42, PR #64)

## Packaging

- **`kotlinx-io-core` and `project(":kcsg")` are now declared `api(...)` rather
  than `implementation(...)`** in `kcsg` and `kcsg-dsl`. Their types appear in
  public signatures, so they belong on the consumer's compile classpath.

  This is the fix for the compilation failure described under Highlights. It
  changes the published Gradle module metadata and the POM scope; it does **not**
  change the ABI, and `apiCheck` cannot observe it — dependency scope is not ABI
  shape. Native targets were never affected, because the Kotlin Gradle plugin
  publishes `implementation` dependencies into `*ApiElements` for klib targets
  regardless. (#51, PR #57)

- **A consumer-resolution smoke test now guards this.**
  `scripts/consumer-smoke.sh` publishes both modules to a throwaway repository
  and compiles two standalone consumer projects against the published
  coordinates. It runs in PR CI as `consumer-resolution-smoke`. The existing
  `:csgs` and `:samples` builds could not have caught the defect, because a
  project composition resolves project dependencies differently from a
  repository resolution — which is exactly how this went unnoticed for the whole
  0.5.0 cycle.

## Maintenance

- PR CI now executes the `commonTest` suites on JS, Wasm and native-linux
  rather than JVM alone, and runs the JS and Wasm suites in headless Chrome with
  a check that proves they ran. (#40, PR #53; #62, PR #70)
- Gradle wrapper 9.6.1 → 9.7.0, kover 0.9.8 → 0.9.9. (PR #71)
- The OpenSCAD oracle subprocess and fixture generation are now bounded, so a
  hung render fails instead of blocking. (PR #55, PR #72)
- `:samples:run` works again — its entry point still referenced the pre-fork
  `eu.mihosoft.vrl.v3d.Main` — and a `check`-time gate now verifies every
  sample entry point resolves. (#45, PR #67)

## Upgrade Notes

- **ABI: unchanged.** All four dumps — `kcsg/api/kcsg.api`,
  `kcsg/api/kcsg.klib.api`, `kcsg-dsl/api/kcsg-dsl.api`,
  `kcsg-dsl/api/kcsg-dsl.klib.api` — are byte-identical to v0.5.0. No source
  changes are required.
- **JVM/JS/Wasm consumers should upgrade.** If you resolved
  `com.monkopedia:kcsg` or `com.monkopedia:kcsg-dsl` from a repository and could
  not reference `CSG`, `Primitive`, `WeightFunction` or `kotlinx.io` types, that
  is #51 and this release fixes it. Plain Maven consumers were affected too —
  the POM carried these dependencies at `<scope>runtime</scope>`.
- **Check any `difference()` result computed against a non-overlapping
  operand.** If you worked around a suspicious `0.0` volume, the workaround is
  no longer needed.
