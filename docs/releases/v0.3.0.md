# v0.3.0 Release Notes

Release date: February 21, 2026

## Highlights

- Added `CSG.remesh()` to normalize polygon meshes into deterministic triangles.
- Added OpenSCAD oracle validation workflow and regression coverage for geometry edge cases.
- Added optional DSL remesh control:
  - `KcsgBuilder.csg(..., remesh: Boolean = true)`
  - `KcsgBuilder.primitive(..., remesh: Boolean = true)`
- Added a quick oracle mode for local runs:
  - `./gradlew :kcsg:oracleTest -Pkcsg.oracle.quick=true`

## Runtime And API Changes

- `CSG.remesh()` now remeshes polygons to triangle faces while preserving:
  - bounds and volume behavior
  - polygon storage metadata
  - vertex weights
- Fixed BSP fallback behavior in `Node.build()` to preserve branch placement in recursive loop cases.
- Fixed tilted extrusion rotation units in `Extrude` to stabilize non-axis-aligned extrusions.
- DSL `csg` delegates now remesh by default. Set `remesh = false` to preserve previous non-remeshed delegate behavior.

## Quality And Validation

- Added OpenSCAD oracle fixture generation and agreement tests across `cgal` and `manifold` backends.
- Added oracle regression tests for:
  - many-reductions union behavior
  - tilted extrude geometry agreement
  - remesh agreement and non-regression checks
- Added broad test coverage expansions across:
  - core `kcsg` API
  - `kcsg-dsl` API
  - hashing and file I/O paths
  - modifier/override contracts

## Tooling And Build

- Added kover coverage verification workflows and tightened quality gates.
- Added public API checklist enforcement for `kcsg` and `kcsg-dsl` API changes.
- Upgraded Kotlin/build toolchain dependencies.

## Upgrade Notes

- If existing DSL scripts rely on original polygon topology from `csg` delegates, update call sites to:

```kotlin
val part by builder.csg(remesh = false) { ... }
```

- For faster local oracle runs, use quick mode and reserve full oracle runs for CI/release validation.
