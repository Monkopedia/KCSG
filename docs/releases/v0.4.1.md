# v0.4.1 Release Notes

Release date: May 22, 2026

## Highlights

- Fixed a CSG cache-hash collision that could cause a stale, incorrect mesh to
  be served for `Cube`-based models.

## Bug Fixes

- **Cube cache-hash collision.** The content hash used for cache keys captured
  only a `Cube`'s `center` and `dimensions`, not its `centered` flag (toggled
  via `noCenter()`), which shifts the cube's geometry by half its dimensions. A
  `Cube` and its `noCenter()` variant therefore produced identical hashes, so a
  hash-keyed cache could serve a stale mesh from a prior edit. `HashingOpOverride`
  now incorporates the `centered` flag, matching `RoundedCube`.

## API Changes

- `Cube.centered` is now a public `var` (previously `private`), mirroring
  `RoundedCube.centered`.

## Tooling And Build

- Bumped `foojay-resolver-convention` 0.9.0 → 1.0.0. The 0.9.0 plugin referenced
  `JvmVendorSpec.IBM_SEMERU`, which Gradle 9 removed, causing a fresh build to
  fail at settings evaluation with the bundled Gradle 9.3.1 wrapper.

## Upgrade Notes

- Cache keys for any `Cube`-containing model change with this release. Existing
  cached entries become cold and recompute correctly on the next run — no manual
  cache clear is required after upgrading.
