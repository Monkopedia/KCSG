# v0.4.5 Release Notes

Release date: July 15, 2026

## Highlights

- Fixes two correctness bugs: string-based OBJ export emitted no faces, and
  degenerate polygons could inject NaN into boolean operations.
- Refreshes the toolchain to Kotlin 2.4.10 and current stable dependencies.

## Bug Fixes

- **`CSG.toObjString()` now emits faces.** The string-based OBJ exporter built
  its vertex block but never populated its face list, producing a vertex block
  and a bare `# Faces` header with no `f` lines — a face-less, degenerate mesh.
  The `csgs` CLI's OBJ export uses this path, so CLI-exported `.obj` files had
  no faces. The exporter now emits one face per polygon (referencing valid
  1-based vertex indices), matching `toObj()`. (#24)

- **Degenerate polygons no longer inject NaN normals into boolean ops.** A
  collinear or duplicate-vertex polygon has a zero-length cross product;
  normalizing it produced a NaN normal that slipped past the zero-normal
  degenerate check (NaN != ZERO) and corrupted BSP boolean operations. Such
  polygons are now flagged invalid (with a finite, zero normal) and filtered
  out of the BSP tree. (#20)

## Maintenance

- **Toolchain / dependency refresh.** Kotlin 2.3.10 → 2.4.10, kotlinx-io
  0.8.0 → 0.9.1, slf4j 2.0.18, kover 0.9.8, vanniktech-maven-publish 0.37.0,
  Gradle 9.6.1. The Kotlin bump does not change the published klib ABI. (#26)
- Removed leftover commented-out pre-Kotlin-port Java across core files. (#25)
- Deduplicated the X/Y/Z modifier weighting math (public API unchanged) (#17),
  and keyed the public-API-checklist CI gate off the BCV ABI diff instead of
  source paths (#19).

## Upgrade Notes

- No source changes required; the public API is unchanged (klib/JVM ABI
  identical to v0.4.4). Hosts that render or export OBJ (e.g. Konstructor)
  should upgrade to pick up the `toObjString()` fix. The toolchain is now
  Kotlin 2.4.10.
