# v0.4.4 Release Notes

Release date: June 16, 2026

## Highlights

- Fixes binary STL import, which could abort partway through any non-trivial
  binary `.stl` file.

## Bug Fixes

- **Binary STL import no longer fails on segment boundaries.** The internal STL
  loader (`STL.file` / `STL.from` for binary STL) passed a *length* where
  kotlinx-io's `Source.readAtMostTo(sink, startIndex, endIndex)` expects an
  *end index*. A single-read source was unaffected, but as soon as a 50-byte
  triangle read straddled a kotlinx-io 8 KB segment boundary — which every
  binary STL beyond ~160 triangles hits — the read went partial, the bad end
  index under-read, and the loader threw `IllegalArgumentException`, aborting
  the import. The loader now passes the correct end index. ASCII STL was never
  affected (separate code path). Covered by a new regression test that parses a
  400-triangle binary STL across several segment boundaries.

## Upgrade Notes

- No source changes required. Hosts that import binary STL (e.g. Konstructor)
  should upgrade to pick up the fix.
